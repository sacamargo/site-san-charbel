# Contexto del proyecto

## Propósito

Construir una landing rápida y clara para la Parroquia San Chárbel de Villa Carolina, Barranquilla, con un panel administrativo mínimo para publicar eventos y actualizar información parroquial.

## MVP acordado

- Inicio.
- Horarios de misas y servicios.
- Eventos y anuncios.
- Información de San Chárbel.
- Contacto, ubicación y WhatsApp.
- Administración de eventos, flyers, horarios y datos de contacto.

## Fuera del MVP

- Donaciones en línea.
- Inscripciones con datos personales.
- Noticias como módulo separado.
- Calendario mensual complejo.
- Galería administrable completa.
- Testimonios, peticiones de oración y streaming.

## Entornos

- DEV: `san-charbel-dev`, utilizado para desarrollo y datos de prueba.
- PROD: proyecto separado, todavía no creado.

## Regla de contenido

Horarios, teléfonos, correos, dirección y redes sociales deben validarse con la parroquia. Las fuentes públicas tienen datos inconsistentes; ningún agente debe inventar o asumir esos valores.
